# Week 1 - Data Acquisition, Cleaning and Preprocessing

## Dataset

UCI Adult (Census Income) Dataset

## Objective

To acquire a publicly available dataset and perform data cleaning and preprocessing using Python.

## Tasks Performed

* Data acquisition
* Initial data exploration
* Missing value detection and treatment
* Duplicate detection and removal
* Data consistency checking
* Outlier detection using IQR
* Categorical encoding
* Numerical feature scaling
* Train-test splitting
* Final data quality checking

## Tools Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* ucimlrepo

## Files

* "data_cleaning_preprocessing.ipynb" - Complete Python code and outputs
* "adult_cleaned.csv" - Cleaned dataset
